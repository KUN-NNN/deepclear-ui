## 范围与限制

- 没有向模型发送请求。长会话、真实 token 统计来源与执行中多面板仍需日常使用验收。
- 真实 web 组合已验证；Electron 桌面完整交互与其他 dsh 版本未逐项回归。
- 未复写终端 ANSI 色。原生用量条保留，可能与紧凑读数同时出现。
- 思考球依赖内部状态文字 class 片段；定位失效只会缺少装饰，不隐藏原文。
- 主题 token 采用可撤销独立层；其他主题同时开启时，重叠 token 的最终颜色取决于加载顺序。

## 代码复核

使用 ask-claude 做只读复核；完整范围请求超时，随后完成设置 runtime 与 Host schema 的聚焦复核。修正卸载期间 pending 清理依赖挂载状态的问题。插件自身的“恢复默认”会写入全部默认值并保留迁移标记，不会复活旧设置。手工删除整个 Host 配置（连同迁移标记）则视为新安装，会再次导入保留的旧 browser key。迁移期间服务重连的重复请求由 revision 防止覆盖，仍可能出现一次冲突提示。Host 就绪前使用旧浏览器设置作首屏兼容回退，因此旧值与 profile 值不同时可能有短暂视觉切换。

最终聚焦复核结论：`VERDICT: APPROVE-WITH-NITS`。随后补上连接 owner 守卫，避免旧设置 scope 的清理覆盖新 scope 的就绪状态。其余显示限制如上；复核不代表完整 UI 交互审计。
